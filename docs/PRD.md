## 2. 제품 비전 및 목표

### 2.1 핵심 문제
HSP(민감한 기질)를 가진 사람들이 자신의 기질을 긍정적으로 받아들이고, 비슷한 사람들과 **안전하게 소통하고 공감받을 수 있는 커뮤니티가 필요하다.**

### 2.2 비전
> "민감한 영혼들이 모여 서로를 이해하고 위로받으며, 자신의 기질을 강점으로 재발견하는 따뜻한 공간"

### 2.3 MVP 목표 (정량적)
1. **초기 사용자 확보**: 3개월 내 500명 활성 사용자
2. **커뮤니티 활동**: 월 300건 이상 게시글/댓글
3. **주간 재방문율**: 55% 이상

---

## 3. 타겟 사용자

### 페르소나 1: 사려깊은 지은 (28세, 마케팅 팀장)
- 민감함으로 인한 자신감 저하, 고립감
- **니즈**: 나 같은 사람이 있을까? 공감 커뮤니티

### 페르소나 2: 창의적인 준호 (32세, 프리랜서 디자이너)
- 이미 기질을 수용했으나, 깊이 있는 연결과 정신 건강 정보 필요
- **니즈**: 비슷한 감성의 사람들과 영감 있는 콘텐츠

## 4. 기능 요구사항 (9개)

| FID | 기능명 | 사용자 스토리 | 상세 요구사항 | 우선순위 |
|-----|--------|-------------|-------------|---------|
| **F-001** | **Google 로그인** | As a 새로운 사용자, I want to Google 계정으로 가입하고 싶고 So that 빠르게 시작할 수 있다 | • Google OAuth 2.0 연동<br/>• 자동 로그인<br/>• 토큰 저장 (JWT) | P0 |
| **F-003** | **로그인/로그아웃** | As a 사용자, I want to 언제든 로그인/로그아웃할 수 있어야 하고 So that 계정을 관리할 수 있다 | • 세션 관리<br/>• 401 시 자동 리다이렉트 | P0 |
| **F-004** | **도서 목록 조회** | As a 사용자, I want to HSP에 도움되는 책을 추천받고 싶고 So that 자기 이해와 성장을 할 수 있다 | • 도서 카드 목록 (Grid)<br/>• 스크롤 로드<br/>• 각 도서 스크랩 버튼<br/>• 상세페이지 없음 | P0 |
| **F-006** | **위인 명언** | As a 사용자, I want to HSP 특성의 위인들의 명언을 읽고 싶고 So that 영감과 위로를 얻을 수 있다 | • 명언 카드 피드 (홈에 노출)<br/>• 명언 + 인물명<br/>• 스크롤 로드 | P0 |
| **F-007** | **게시글 조회/검색** | As a 사용자, I want to 다른 사람들의 경험을 읽고 싶고 So that 혼자가 아니라는 느낌을 받을 수 있다 | • 게시글 리스트 (시간 역순)<br/>• 제목, 작성자, 작성일, 본문 미리보기<br/>• 카테고리 필터<br/>• 페이지네이션 | P0 |
| **F-008** | **게시글 작성** | As a 사용자, I want to 내 경험을 나눌 수 있어야 하고 So that 공감받고 위로받을 수 있다 | • 제목 + 본문 (textarea, RTE 없음)<br/>• 카테고리 선택 필수<br/>• 이미지 첨부 없음<br/>• 필수값 검증 | P0 |
| **F-009** | **댓글 작성/삭제** | As a 사용자, I want to 게시글에 댓글로 대화하고 싶고 So that 깊이 있는 소통을 할 수 있다 | • 댓글 리스트 (최신순)<br/>• 댓글 작성 폼<br/>• 본인 댓글만 삭제 가능<br/>• 수정 기능 없음 | P0 |
| **F-010** | **공감 반응** | As a 사용자, I want to 게시글/댓글에 공감 표시를 하고 싶고 So that 따뜻한 위로를 전할 수 있다 | • ♥ 하트 버튼 (토글)<br/>• 실시간 공감 수 업데이트<br/>• 내 공감 여부 표시 | P0 |
| **F-012** | **마이페이지 (간소)** | As a 사용자, I want to 내 프로필과 활동을 관리할 수 있어야 하고 So that 내 정보를 알 수 있다 | • 프로필 조회 (닉네임, 가입일)<br/>• 로그아웃 버튼<br/>• 통계/내 게시글 없음 | P1 |

## 5. 비기능 요구사항 (요약)

| 항목 | 목표 |
|------|------|
| **성능** | 페이지 로딩 < 3초, API 응답 < 500ms |
| **보안** | OAuth 2.0, JWT 토큰, HTTPS 필수 |
| **접근성** | WCAG 2.1 Level AA, 키보드 네비게이션 지원 |
| **반응형** | 모바일 우선 (320px 이상) |

## 6. 정보 구조 및 사이트맵

```
센시 서비스

비로그인
├── / (홈/랜딩)
├── /login (Google 로그인)

로그인 후
├── / (커뮤니티 피드) ← 메인 페이지
│   ├── 도서 카드 (상단)
│   ├── 위인 명언 (상단)
│   └── 게시글 리스트 (메인)
├── /community (게시글 목록)
├── /community/new (게시글 작성)
├── /community/:id (게시글 상세 + 댓글)
├── /books (도서 목록)
└── /mypage (프로필 + 로그아웃)
```

## 10. 핵심 용어

| 용어 | 정의 |
|------|------|
| **HSP** | Highly Sensitive Person - 타고난 신경계 민감성으로 자극을 깊이 있게 처리하는 기질 (약 15-20%) |

| **큐레이션** | 전문가가 선정하여 추천하는 도서/명언 모음 |
