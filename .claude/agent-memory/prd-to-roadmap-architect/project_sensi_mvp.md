프론트엔드 페이지 컴포넌트, 레이아웃, 라우터, authStore, useApi 훅, Axios 인스턴스가 모두 구성되어 있으나, 모든 API 호출 지점이 `// TODO: API 연동` 플레이스홀더 상태다. 백엔드 서버가 전혀 없는 것이 핵심 갭이다.

**Why:** 프론트엔드 스타터 킷 정리 후 MVP PRD가 확정되었고, 이제 실제 개발 착수를 위한 로드맵이 필요한 시점이다. 9개 기능(F-001, F-003, F-004, F-006, F-007, F-008, F-009, F-010, F-012) 모두 P0/P1이다.

**How to apply:** 이 프로젝트에 대한 후속 대화에서는 "FE 구조는 이미 있음, BE 구현이 블로커"라는 컨텍스트를 전제로 답변한다. Phase 1(인증/백엔드 기반)이 모든 Phase의 선행 조건이다.
